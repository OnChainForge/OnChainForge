# OnChainForge

🔗 [Portfolio](https://portfolio-agpx.onrender.com)

Backend Engineer specialized in Blockchain Data and On-Chain Analytics.

I build systems that listen to Ethereum in real time, process and normalize transaction data, and turn raw on-chain activity into explainable risk scores and alerts — no black-box models, just transparent rule-based logic you can trace end to end.

## Stack

Python · FastAPI · SQLAlchemy · PostgreSQL/SQLite · web3.py · Ethereum RPC · Docker · Redis · REST APIs

## Projects

### [Risk Monitoring Engine](https://github.com/OnChainForge/risk-monitoring-engine)
Configurable rule engine for real-time Ethereum transaction risk scoring. Analyze any transaction on-demand by hash, or stream events into it continuously.
[Live demo](https://risk-monitoring-engine-1.onrender.com) · [Video](https://youtu.be/KVdkqj9M1R0)

### [Blockchain Event Pipeline](https://github.com/OnChainForge/blockchain-event-pipeline)
Background listener that monitors new Ethereum blocks, normalizes transactions, and forwards high-value ones to the Risk Monitoring Engine.
[Live demo](https://blockchain-event-pipeline-fronted.onrender.com) · [Video](https://youtu.be/vAqVrAKZU7k)

### [Whale Alert v2.0](https://github.com/OnChainForge/whale-alert-v2)
Real-time detection of large ETH transactions ("whales") with atomic deduplication via Redis.
[Live demo](https://whale-alert-v2.onrender.com) · [Video](https://youtu.be/1uu52D18Oqc)

### [On-Chain Intelligence Platform](https://github.com/OnChainForge/onchain-intelligence-platform)
Wallet risk scoring platform: register addresses, get an explainable 0-100 score based on recent on-chain activity, receive alerts on threshold breach.
[Live demo](https://onchain-intelligence-platform-1.onrender.com) · [Video](https://youtu.be/7zLiWxaTAB4)
